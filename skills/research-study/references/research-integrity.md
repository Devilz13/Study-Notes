# Research Integrity and Evidence Rules

Read this reference for literature searches, novelty claims, paper reviews, numerical checks, advisor analysis, and any work involving unpublished material.

## Evidence Labels

Keep these categories distinct in notes and outputs:

| Label | Meaning |
| --- | --- |
| Author claim | The paper or author states it; it has not been independently verified. |
| Verified | Supported by a checked primary source, supplied data, or a reproduced calculation. |
| Inference | A reasoned interpretation from identified evidence. |
| Unknown | The available material is insufficient or contradictory. |

Do not upgrade an author claim to a verified fact merely because it is repeated in the abstract, conclusion, or a secondary source.

## Source Discipline

- Prefer the paper, supplementary material, official venue guidance, datasets, code repositories, standards, and other primary sources.
- Use current official sources for venue rules, page limits, deadlines, scoring forms, and policies because they can change.
- Verify bibliographic metadata before presenting a citation as real. Include a DOI, stable publisher page, arXiv identifier, or equivalent locator when practical.
- Do not cite a search-result snippet as if the full source was reviewed.
- State the search scope and date for novelty or literature-coverage claims. Phrase conclusions as “not found in the searched corpus,” not “does not exist.”

## Paper-Level Traceability

Tie consequential observations to the most precise locator available: page, section, paragraph, figure, table, equation, appendix, or LaTeX file and label. If OCR changed pagination or structure, cite both the source page and OCR page marker.

## Numerical Verification

- Recompute percentages, deltas, ratios, aggregates, confidence intervals, and other derivable values when the inputs are available.
- Distinguish absolute change from relative change and percentage points from percent.
- Check sample sizes, denominators, units, rounding, seeds/runs, uncertainty intervals, and metric direction.
- Treat unreadable plots and missing raw values as limitations; do not estimate precise numbers from a figure unless clearly labeled as an approximation.
- Record the formula and inputs for any calculation that affects a finding.

## Confidentiality and External Processing

Peer-review manuscripts, unpublished drafts, and proprietary datasets may be confidential. Use local processing by default. Before any external upload, confirm that the user is authorized to share the material and understands which service will receive it. If venue or institutional policy prohibits third-party processing, do not upload.

Never infer conflicts of interest from names alone. If acting as a reviewer, ask the user to handle formal conflict declarations under the venue's policy.

## Responsible Critique

- Critique the work, not the authors.
- Separate fixable presentation problems from flaws that undermine a central claim.
- Do not use uncertain criticism as a primary rejection reason; frame it as a question or verification need.
- Make scores and recommendations consistent with the written evidence.
- Surface ethical, privacy, safety, demographic, or dual-use concerns only when supported and relevant.
