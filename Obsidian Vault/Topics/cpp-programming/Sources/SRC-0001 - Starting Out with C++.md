# SRC-0001 - Starting Out with C++

## Identity

Tony Gaddis. *Starting Out with C++: From Control Structures through Objects*. Ninth Global Edition. Pearson Education, 2019. ISBN 978-1-292-22233-2.

Repository file: [Open PDF on GitHub](https://github.com/Devilz13/Study-Notes/blob/main/Academic%20Source%20Library/cpp-programming/Sources/Accepted/SRC-0001%20-%20Starting%20Out%20with%20C%2B%2B%20-%20Ninth%20Global%20Edition.pdf)

## Role and limits

Anchor textbook for programming fundamentals through OOP, generic programming, STL, linked structures, recursion, and trees. Code must be compiled and tested; current C++20/23 guidance requires newer primary sources.

## Structured extracts

- Chapters 1-7: programming foundations, control flow, functions, arrays, and vectors.
- Chapters 8-12: algorithms, pointers, strings, structures, and files.
- Chapters 13-17: classes, inheritance, polymorphism, exceptions, templates, and STL.
- Chapters 18-21: linked lists, stacks, queues, recursion, and binary trees.

These are table-of-contents observations, not yet verified proposition-level notes.
