# Misconceptions: Cross-Topic Computing Index

Record the incorrect model, why it was tempting, corrective evidence, and a transfer question that distinguishes the models.

| Candidate misconception | Corrective distinction | Transfer check |
| --- | --- | --- |
| Similar diagrams mean the systems work the same way | A diagram selects relations for a purpose; shared shape does not prove shared mechanism | Which assumptions differ between an OSI layer and a software architecture layer? |
| Testing and research validation are interchangeable | Tests check specified behavior; research validation addresses whether evidence supports a claim | Can all unit tests pass while the research conclusion remains unsupported? |
| More links create better memory | Links should encode meaningful relations and evidence, not mere co-occurrence | Can you name the relation and the boundary where it stops applying? |
