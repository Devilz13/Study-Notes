# Research questions: Cross-Topic Computing Index

## Primary question

Which reusable reasoning patterns connect networking, computing research, systems analysis, and C++ without erasing important differences?

## Subquestions

- How do layers, models, and abstractions reduce complexity in each subject?
- How do research validity, requirements validation, testing, and network diagnosis differ while sharing an evidence loop?
- How does decomposition create interfaces and traceability across protocols, systems, and programs?
- How do reliability, security, and failure diagnosis change at each level?
- Which practical projects exercise all four subjects together?

## Explicit exclusions

- Creating links solely because terms co-occur
- Treating analogies as source evidence
- Promoting NotebookLM synthesis without checking both linked subject sources

## Evidence needed

- Verified concept notes from at least two subject workspaces for every canonical cross-topic edge
- Reproducible project or recall evidence before promotion to stable memory
