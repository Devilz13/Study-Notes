# Learning Loop and Memory Promotion

A concept stays `seed` until its source claim is checked, becomes `developing` after verification, becomes `stable` after successful retrieval or application with contradictions represented, and becomes `superseded` when better evidence replaces it.

The loop is: NotebookLM candidate synthesis -> ChatGPT verification -> atomic Obsidian note -> retrieval/application -> misconception update -> next review.
