# Research questions: Networking Fundamentals

## Primary question

How do layered protocols, addressing, media, and device configuration cooperate to deliver data reliably across a small internetwork?

## Subquestions

- What responsibility belongs to each OSI and TCP/IP layer?
- How are application data encapsulated and forwarded between hosts?
- How do subnet masks divide IPv4 network and host portions?
- How do Ethernet framing, MAC addressing, switching, and physical media interact?
- Which tests isolate local-stack, local-LAN, gateway, name-resolution, and remote-path failures?

## Explicit exclusions

- Treating this 2008 book as sufficient evidence for current Cisco certification objectives
- Assuming legacy IPv4-first design is current best practice
- Production security architecture without current standards and vendor documentation

## Evidence needed

- `SRC-0001` for foundational definitions and chapter exercises
- Current IETF RFCs and current Cisco/standards documentation for later updates
- Reproducible Packet Tracer or physical-lab observations for applied mastery
