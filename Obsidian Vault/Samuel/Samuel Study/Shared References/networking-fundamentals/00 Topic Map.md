# Networking Fundamentals

## Scope

Foundational network communication from application to physical media, IPv4 addressing and subnetting, Ethernet, cabling, device configuration, and connectivity testing. The current anchor is a 2008 Cisco Press textbook, so protocol fundamentals are in scope while current certification policy and modern implementation guidance require newer sources.

## Learning target

Explain how data moves through layered network models, design a small IPv4 address plan, distinguish Ethernet/media choices, and configure and test a small network while diagnosing the failing layer.

## Prerequisites

- Binary and decimal conversion
- Basic computer hardware and operating-system concepts
- Comfort reading simple command output
