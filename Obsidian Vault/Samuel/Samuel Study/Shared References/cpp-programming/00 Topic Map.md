# C++ Programming

## Scope

Programming fundamentals through control flow, functions, arrays, searching/sorting, pointers, files, object-oriented programming, exceptions, templates, STL containers/algorithms, linked structures, recursion, and trees. The anchor is a 2019 global edition built largely around C++11-era language features.

## Learning target

Design, implement, test, and explain small-to-medium C++ programs; reason about ownership and data structures; and choose between manual structures and standard-library abstractions without hiding failure modes.

## Prerequisites

- Basic computer operation and file management
- Algebraic expressions and logical conditions
- Willingness to compile, test, and debug every example
