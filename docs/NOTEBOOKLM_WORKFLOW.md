# NotebookLM workflow

Checked on 2026-10-18. The current product is labelled Gemini Notebook. The same study-processing role applies.

## Notebook scope

Use seven ecosystem scopes: ICT111, ICT201, the four shared textbook subjects, and a cross-topic index. Reuse an existing matching notebook after checking its source list. Do not infer module mappings from a similar subject title.

Keep actual account links, notebook IDs, source counts, sharing state, and configuration results in a private connection record. Do not commit them to this public repository. Verify the current account's notebook list before claiming creation or import. Keep private sources in private notebooks.

## Process later files

1. Organize and screen the module files. Update its evidence ledger.
2. Upload only the authorized files to the matching private Drive folder.
3. Record actual Drive links. Rebuild the manifests.
4. Open the matching notebook. Import the selected accepted or contextual sources.
5. Verify the imported source titles and coverage.
6. Use `01 NotebookLM Processing Prompt.md` from that source scope.
7. Return the cited CHATGPT / CLAUDE HANDOFF as `unverified_synthesis`.
8. Check material claims against the original page or slide. Then update Obsidian notes.

The cross-topic notebook receives curated, source-linked summary exports. It cannot use another notebook itself as source evidence. Keep the original supporting source references attached.

Do not run a factual study task in an empty notebook. Empty folders and notebook shells are not source material. File organization does not automatically upload or process source contents.

## Verification states

Track notebook creation, source upload, import, processing, and memory promotion separately. Never use `ready` to mean all five steps are complete. Existing textbook ledgers retain their previous upload authorization state.

Google Drive imports may refresh from the source file; direct uploads can be snapshots. Verify the current import mode and source status before relying on a refresh.

Official source-format and import guidance: <https://support.google.com/gemininotebook/answer/16215270?hl=en>.
